# راه‌اندازی پراکسی امن برای «دستیار هوشمند»

بخش «دستیار هوشمند» اپ (چت گیاه‌پزشکی + تحلیل تصویر گیاه) از **DeepSeek**
استفاده می‌کند. برای این کار به یک کلید API نیاز دارید. ساده‌ترین روش این
است که این کلید را مستقیم در `config.py` بگذارید (توضیح کامل در docstring
بالای همان فایل) — برای تست شخصی روی دسکتاپ یا استفاده‌ی کاملاً خصوصی همین
کافی است.

اما اگر می‌خواهید APK را **عمومی منتشر کنید** (گیت‌هاب عمومی، فروشگاه، لینک
اشتراکی)، آن روش کافی نیست: هر فایل APK یک بسته‌ی عمومی است و هرکسی که آن
را دریافت کند می‌تواند هر رشته‌ای که داخل کد پایتون نوشته شده باشد (از
جمله یک کلید API در `config.py`) را استخراج کند. اگر این اتفاق بیفتد،
هرکسی می‌تواند با کلید شما درخواست بفرستد و هزینه‌اش از حساب شما کسر شود.

راه‌حل این فایل: یک واسطه‌ی کوچک و رایگان (Cloudflare Worker) بین اپ و
DeepSeek قرار می‌گیرد. کلید فقط روی این واسطه (سمت سرور) ذخیره می‌شود؛ اپ
فقط با آدرس واسطه حرف می‌زند و هیچ‌وقت خودِ کلید را نمی‌بیند.

```
[اپ اندروید] --(بدون کلید)--> [Cloudflare Worker] --(با کلید، سمت سرور)--> [DeepSeek API]
```

## مراحل (حدود ۵ دقیقه، کاملاً رایگان)

1. یک کلید API از **https://platform.deepseek.com** بسازید (بخش API Keys).
2. یک حساب رایگان در **https://dash.cloudflare.com** بسازید (نیاز به کارت
   بانکی ندارد).
3. از منوی سمت چپ: **Workers & Pages → Create → Create Worker**. یک اسم
   بدهید (مثلاً `plant-vet-proxy`) و روی Deploy بزنید (فعلاً با کد پیش‌فرض).
4. روی Worker ساخته‌شده کلیک کنید → **Edit code**. کل کد پیش‌فرض را پاک کنید
   و محتوای فایل `cloudflare-worker.js` (همین پوشه) را جای آن بگذارید →
   **Deploy**.
5. برگردید به صفحه‌ی Worker → **Settings → Variables and Secrets → Add**:
   - نام: `DEEPSEEK_API_KEY`  |  مقدار: کلید واقعی از مرحله ۱  |  نوع: **Secret**
   - (اختیاری ولی پیشنهادی) نام: `APP_SHARED_SECRET`  |  مقدار: یک رشته
     دلخواه و طولانی (مثلاً یک UUID) | نوع: **Secret**
     این کار باعث می‌شود فقط اپ خودتان بتواند از این Worker استفاده کند، نه
     هرکسی که آدرس آن را حدس بزند یا پیدا کند.
6. بالای صفحه‌ی Worker، آدرس آن را کپی کنید (چیزی شبیه
   `https://plant-vet-proxy.your-name.workers.dev`).
7. فایل `config.py` را باز کنید و:
   ```python
   PROXY_URL = "https://plant-vet-proxy.your-name.workers.dev"
   APP_SHARED_SECRET = ""  # اگر مرحله ۵ (بخش اختیاری) را انجام دادید، همان رشته را اینجا بگذارید
   ```
   وقتی `PROXY_URL` پر باشد، `ai_vet_screen.py` خودکار به‌جای تماس مستقیم با
   DeepSeek، از همین پراکسی استفاده می‌کند — دیگر نیازی به `DEEPSEEK_API_KEY`
   در همان فایل نیست (می‌توانید خالی‌اش بگذارید).
8. تغییرات را کامیت و push کنید تا نسخه بعدی APK با تنظیمات درست ساخته شود
   (توجه: چون `config.py` عمداً در `.gitignore` است، این تغییر با push
   منتقل نمی‌شود مگر روش گیت‌هاب‌اکشن زیر را هم انجام دهید).

## ساخت خودکار APK با گیت‌هاب اکشن — بدون این‌که کلید وارد گیت شود

چون `config.py` در `.gitignore` است، چیزی که در آن می‌نویسید هرگز push
نمی‌شود؛ یعنی بیلد گیت‌هابی (`.github/workflows/build.yml`) به‌طور پیش‌فرض
بدون کلید/پراکسی اجرا می‌شود و APK نهایی پیام «نیاز به تنظیم» نشان می‌دهد.
برای این‌که بیلد خودکار هم کار کند، مقدارها را به‌جای `config.py`، به‌عنوان
**GitHub Secret** اضافه کنید:

در ریپازیتوری گیت‌هاب: **Settings → Secrets and variables → Actions →
New repository secret** و هرکدام از این‌ها را که لازم دارید اضافه کنید:
- `DEEPSEEK_API_KEY` (برای حالت مستقیم) **یا** `PROXY_URL` (برای حالت پراکسی)
- `APP_SHARED_SECRET` (اختیاری، فقط اگر از پراکسی با Secret استفاده می‌کنید)

مرحله‌ی `scripts/generate_config.py` در `build.yml` همین Secretها را در
زمان بیلد می‌خواند و `config.py` را می‌سازد — کلید هیچ‌وقت در کد یا تاریخچه‌ی
گیت ذخیره نمی‌شود.

## تست سریع پراکسی (اختیاری، بدون نیاز به اپ)

از ترمینال:
```bash
curl -X POST https://plant-vet-proxy.your-name.workers.dev \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-v4-flash","max_tokens":100,"messages":[{"role":"user","content":"سلام"}]}'
```
اگر یک پاسخ JSON از DeepSeek برگشت، پراکسی درست کار می‌کند.

## نکات

- **رایگان بودن**: پلن رایگان Cloudflare Workers روزانه ۱۰۰,۰۰۰ درخواست
  می‌دهد که برای یک اپ شخصی/هابی کاملاً کافی است.
- **محدودیت مصرف بیشتر (اختیاری)**: در داشبورد Cloudflare، بخش
  **Security → WAF → Rate limiting rules** می‌توانید بدون نوشتن کد یک
  محدودیت مثل «حداکثر ۲۰ درخواست در دقیقه از هر IP» هم اضافه کنید تا از
  سوءمصرف جلوگیری شود.
- **هزینه DeepSeek**: این پراکسی فقط مسیر ارتباط را امن می‌کند؛ مصرف واقعی
  API همچنان طبق قیمت‌گذاری DeepSeek از حساب شما کسر می‌شود. برای محدود
  کردن هزینه، در **https://platform.deepseek.com** بخش Billing/Usage
  می‌توانید سقف مصرف تعیین کنید.
- اگر ترجیح می‌دهید به‌جای Cloudflare Workers از سرویس دیگری (مثلاً Vercel
  یا یک سرور شخصی) استفاده کنید، فقط کافی است همان منطق `cloudflare-worker.js`
  (دریافت درخواست از اپ → افزودن کلید → فوروارد به DeepSeek → برگرداندن
  پاسخ) را در آن پلتفرم پیاده کنید؛ کد `ai_vet_screen.py` تغییری نیاز ندارد،
  فقط کافی‌ست `PROXY_URL` را به آدرس جدید تغییر دهید.
