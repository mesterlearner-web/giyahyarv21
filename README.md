# 🌿 گیاهیار - برنامه مراقبت از گیاهان

برنامه اندروید برای مراقبت از گیاهان آپارتمانی، گل‌های خانگی و درختان میوه.
ساخته‌شده با **Kivy** (Python) — قابل اجرا روی **Android** و **Desktop**.

---

## 📱 امکانات

| بخش | توضیح |
|-----|-------|
| 🌿 **لیست گیاهان** | ۸۵ گیاه با اطلاعات کامل و عکس واقعی + افزودن گیاه دلخواه |
| 🔍 **جستجو** | جستجوی فوری در نام، نام علمی، دسته‌بندی |

## 🚀 نصب و راه‌اندازی

### اجرای روی Desktop (تست سریع)
```bash
pip install kivy==2.3.0 pillow requests arabic-reshaper python-bidi plyer
cd plant_care_app
python main.py
```

### ساخت APK اندروید

بیلد کیوی برای اندروید نیاز به Android SDK/NDK و چند گیگابایت فضا دارد،
پس دو راه دارید:

#### روش ۱ (پیشنهادی): بیلد آنلاین با GitHub Actions — بدون نیاز به لینوکس

این پروژه از قبل فایل `.github/workflows/build.yml` را دارد که APK را
روی سرورهای گیت‌هاب می‌سازد:

1. یک ریپازیتوری جدید در گیت‌هاب بسازید و **محتوای همین پوشه** (`plant_care_app`)
   را در ریشه‌ی آن push کنید (نه خودِ پوشه را با یک لایه‌ی اضافه).
2. به تب **Actions** ریپو بروید؛ بیلد به‌صورت خودکار شروع می‌شود (یا از
   همان‌جا با «Run workflow» دستی اجرایش کنید).
3. حدود ۱۵ تا ۲۵ دقیقه صبر کنید (بار اول بیشتر طول می‌کشد چون SDK/NDK
   دانلود می‌شود).
4. روی آخرین اجرا کلیک کنید → پایین صفحه بخش **Artifacts** → دانلود
   `giyahyar-apk`.

#### روش ۲: بیلد محلی (اگر Linux/Mac/WSL دارید)
```bash
pip install buildozer cython
# Linux/Mac:
sudo apt-get install -y python3-pip build-essential git python3 python3-dev \
    ffmpeg libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev libsdl2-ttf-dev \
    libportmidi-dev libswscale-dev libavformat-dev libavcodec-dev zlib1g-dev

cd plant_care_app
buildozer android debug
# فایل APK در پوشه bin/ ساخته می‌شود
```

### نصب روی گوشی
```bash
adb install bin/plantcare-*-arm64-v8a-debug.apk
# یا فایل APK را مستقیم روی گوشی کپی و نصب کنید
```

## ⚙️ راه‌اندازی دستیار هوشمند (اختیاری)

این بخش (چت + تحلیل تصویر گیاه) به یک کلید API از **DeepSeek** نیاز دارد.
یک کپی از `config.py.example` با نام `config.py` بسازید و کلید خود را
(از https://platform.deepseek.com) در آن بگذارید — برای تست شخصی همین
کافی است، چون `config.py` از قبل در `.gitignore` است و push نمی‌شود.

اگر اپ را **عمومی منتشر می‌کنید**، کلید مستقیم در `config.py` را از داخل
APK می‌شود استخراج کرد؛ برای آن حالت، راهنمای کامل راه‌اندازی امن (پراکسی
رایگان Cloudflare، حدود ۵ دقیقه) در **[`server/README.md`](server/README.md)**
است.

اگر این بخش را راه‌اندازی نکنید، بقیه‌ی اپ کامل کار می‌کند؛ فقط صفحه
«دستیار هوشمند» پیام «نیاز به تنظیم» نشان می‌دهد.

## 💡 نکات مهم

- **تایمرها** در فایل `timers_data.json` روی خودِ گوشی ذخیره می‌شوند
- **گیاهان اضافه‌شده** در فایل `custom_plants.json` روی خودِ گوشی ذخیره می‌شوند
- **دستیار هوشمند** (چت و تحلیل تصویر) نیاز به اینترنت و یک کلید DeepSeek در
  `config.py` دارد (بالا را ببینید)
- **بنر تبلیغاتی** در پایین همه صفحات (۳۰dp ≈ ۱ سانتی‌متر)
- گیاهانی که عکس واقعی ندارند (مثل گیاهان سفارشی که خودتان اضافه می‌کنید)
  به‌جای عکس، یک آیکون رنگی بر اساس دسته‌بندی نشان می‌دهند
